苹果风液态玻璃博客主题：内容不装盒子，玻璃只给控件。

== 描述 ==

PureAura 是一套为中文长文阅读设计的 WordPress 主题。它把"液态玻璃"当作功能性的材质系统，而不是装饰滤镜：底景、内容、控件三层各司其职，只有能点的东西才使用玻璃。

主要特性：

* 悬浮玻璃导航条：随指针移动的高光，深浅色自动适配
* 文章目录：自动从正文的二级、三级标题生成，滚动时高亮当前章节
* 阅读进度条：顶部细线随滚动推进
* 三种外观：浅色、深色、跟随系统，读者可自行切换并记住选择
* 三种列表布局：编辑式、两列网格、极简列表
* 全屏磨砂搜索层，支持按分类浏览，快捷键 / 或 Ctrl+K
* 代码块一键复制、正文图片点击放大
* 相关文章、作者卡片、上下篇、浏览量、预计阅读时长
* 后台二十余项设置：强调色、玻璃模糊与不透明度、圆角、内容宽度、背景样式、页脚备案信息等
* 中国大陆站点所需：ICP 备案号、公安备案号一栏直接填
* 无 jQuery、无第三方库、系统字体，首屏快
* 响应式：桌面为悬浮导航条，手机为顶栏 + 底部悬浮工具条

== 安装 ==

1. 后台「外观 → 主题 → 添加新主题 → 上传主题」，选择 pureaura.zip 安装并启用。
2. 进入「外观 → 自定义」，按需调整颜色、玻璃强度、布局与页脚信息。
3. 在「外观 → 菜单」中创建菜单并指定到「主导航」。没有设置菜单时，主题会自动列出版块分类。

== 常见问题 ==

= 目录为什么不显示？ =
目录只从正文里的一级、二级标题生成。如果文章没有使用「标题」区块，目录会自动隐藏。

= 玻璃看起来不明显？ =
玻璃需要背后有内容才能体现。可以在「外观 → 自定义 → 布局」里把背景改为自定义图片，或在「外观与材质」里降低玻璃不透明度。

= 浏览量从哪里来？ =
主题在文章被访问时记录一次，不做去重，也不统计爬虫。数据存在文章的自定义字段 pureaura_views 中。
